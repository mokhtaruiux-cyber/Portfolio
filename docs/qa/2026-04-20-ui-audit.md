## Baseline Summary

The site started with a strong homepage and polished motion, but secondary routes were materially weaker. The main gaps were dead vertical space on short pages, inconsistent heading hierarchy, generic interior-page framing, a detached footer on archive/utility routes, and duplicate extracted text from the animated hero heading.

## Implementation Update

Status: **Primary fixes implemented on 2026-04-20**

### Implemented

1. Route-level heading hierarchy was normalized.
   - `/projects`, `/blog`, and `404` now render a single route-level `h1`.
   - The homepage work section was corrected from `h3` to `h2`.

2. Short-page spacing was tightened.
   - Removed forced full-height behavior from archive and 404 route composition.
   - Reduced bottom spacing on archive and utility routes.
   - Reworked footer spacing into route-aware variants instead of one oversized global value.

3. Interior-page framing was upgraded.
   - Added a shared `PageIntro` pattern for archive and utility routes.
   - `/projects`, `/blog`, and `404` now use a stronger page-intro block instead of plain stacked headings.

4. Navbar chrome was reduced on non-home routes.
   - The interior navbar now uses quieter background treatment.
   - The schedule/CTA button no longer uses the full glow treatment outside the homepage.

5. Hero heading semantics were cleaned up.
   - The animated text path is now decorative only.
   - The parent `h1` carries the accessible label, removing duplicate extracted heading text.

### Second Pass

Follow-up fixes were applied after visual review of the archive and blog pages:

1. Navbar styling was returned to the homepage system.
   - Removed the alternate interior-route chrome treatment that introduced the stronger border mismatch.
   - Blog and projects now use the same nav shell styling as home.

2. Archive and blog headers were simplified.
   - Removed the card-like header background, border, and shadow treatment.
   - Kept the shared intro component, but converted it to a plain heading block aligned with the site’s main heading rhythm.

3. Blog heading styling was brought back into the site heading system.
   - The blog index now uses the same plain heading and supporting copy rhythm as the rest of the site instead of the card-style utility header.

4. The projects archive now uses the same stacked-scroll interaction as the homepage work section.
   - Archive browsing behavior is now consistent with the portfolio’s core UX pattern instead of switching to a simple linear list.

### Third Pass

Follow-up fixes were applied after another route-level review:

1. Archive and blog content were offset below the fixed navbar.
   - Added explicit top spacing to both route sections so the eyebrow and heading no longer start under the nav shell.

2. Projects archive filtering was restored.
   - Reintroduced the segmented filter tabs on `/projects`.
   - Archive cards now respond to the same category filter model already used on the homepage work section.

3. Archive and blog headings now use the accent-word treatment again.
   - The route titles now split onto two lines with the second word highlighted in the accent color.
   - Accessible heading names are preserved through `aria-label`, so visual styling does not break route semantics or tests.
